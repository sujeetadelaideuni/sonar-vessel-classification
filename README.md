# Vessel classification from passive sonar: scratch CNN vs PANNs CNN14

Final project for COMP 5064, Programming for Artificial Intelligence and Machine Learning 2 (University of Adelaide, 2026 Semester 2). Author: Sujeet Ghosh.

**Question.** Does fine-tuning an AudioSet-pretrained model (PANNs CNN14) beat a small CNN trained from scratch at classifying vessel type (background, cargo, passengership, tanker, tug) from one-second hydrophone clips? Does the answer change at other distances (VTUAD scenarios S1, S2, S3) and on a second dataset (DeepShip)?

**Short answer.** On identical 24,000 training clips the scratch CNN leads on all three VTUAD test sets (by 0.156 to 0.205 macro-F1), and PANNs leads only on DeepShip (by 0.071), where both models are weak. All final runs are single-seed, so read this as a result for these settings, not a general claim about transfer learning. The full analysis is in the written report.

## Results (macro-F1 on the clean test sets, accuracy in brackets)

| Model (training clips) | S1 | S2 | S3 | DeepShip |
|---|---|---|---|---|
| Scratch CNN, S1 only (36,510) | 0.773 (0.888) | 0.530 (0.677) | 0.464 (0.660) | 0.285 (0.321) |
| Scratch CNN, S1+S2+S3 (24,000) | 0.613 (0.771) | 0.687 (0.779) | 0.670 (0.772) | 0.371 (0.388) |
| PANNs CNN14, S1 only (4,000) | 0.428 (0.576) | 0.391 (0.514) | 0.347 (0.531) | 0.344 (0.330) |
| PANNs CNN14, S1+S2+S3 (24,000) | 0.457 (0.591) | 0.502 (0.608) | 0.465 (0.605) | 0.442 (0.426) |

The two 24,000-clip rows are the fair head-to-head comparison. The S1-only rows use different training-set sizes and are context only. Every number comes from the files in `results/`. `report/results_table.csv` and `.md` are generated by `summarise.py`; they round twice, so one cell (PANNs S1-only on S2) prints 0.392 where the JSON value 0.39145 rounds to 0.391.

## Reproducing the results

Python with PyTorch. The final runs used Google Colab with a Tesla T4 GPU. Run everything from the repository folder.

```
pip install -r requirements.txt

# 1. Cache the audio (once). Put VTUAD in data/ and DeepShip in deepship_data/
python sonar.py cache --root data --out cache
python sonar.py cache_deepship --root deepship_data --out cache

# 2. Clean test sets (removes test clips that also occur in train or validation)
python sonar.py clean_test --scenario inclusion_2000_exclusion_4000
python sonar.py clean_test --scenario inclusion_3000_exclusion_5000
python sonar.py clean_test --scenario inclusion_4000_exclusion_6000

# 3. Final runs (the four model rows in the table above)
python sonar.py train --scenario inclusion_2000_exclusion_4000 --model cnn --epochs 15 --eval_on inclusion_2000_exclusion_4000-clean inclusion_3000_exclusion_5000-clean inclusion_4000_exclusion_6000-clean deepship
python sonar.py train --scenario inclusion_2000_exclusion_4000 inclusion_3000_exclusion_5000 inclusion_4000_exclusion_6000 --model cnn --epochs 15 --max_train 24000 --eval_on inclusion_2000_exclusion_4000-clean inclusion_3000_exclusion_5000-clean inclusion_4000_exclusion_6000-clean deepship
python sonar.py train --scenario inclusion_2000_exclusion_4000 --model panns --ckpt "Cnn14_mAP=0.431.pth" --epochs 6 --freeze_epochs 3 --unfreeze last2 --max_train 4000 --bs 16 --eval_on inclusion_2000_exclusion_4000-clean inclusion_3000_exclusion_5000-clean inclusion_4000_exclusion_6000-clean deepship
python sonar.py train --scenario inclusion_2000_exclusion_4000 inclusion_3000_exclusion_5000 inclusion_4000_exclusion_6000 --model panns --ckpt "Cnn14_mAP=0.431.pth" --epochs 6 --freeze_epochs 3 --unfreeze last2 --max_train 24000 --eval_on inclusion_2000_exclusion_4000-clean inclusion_3000_exclusion_5000-clean inclusion_4000_exclusion_6000-clean deepship

# 4. 50 Hz mel-floor ablation (scratch CNN restricted to CNN14's mel range)
python sonar.py train --scenario inclusion_2000_exclusion_4000 --model cnn --epochs 15 --fmin 50 --eval_on inclusion_2000_exclusion_4000-clean

# 5. Tables and figures, and the data audit
python summarise.py
python check_data.py

# 6. Demo on ten real clips
python demo.py --test inclusion_4000_exclusion_6000-clean --seed 3 --per_class 2 --models "models/cnn_scratch_n24000_s0_s1+s2+s3.pt" "models/panns_ft-last2_n24000_s0_s1+s2+s3.pt"
```

`notebooks/sonar_cnn_vs_panns_final_run.ipynb` is the executed Colab version of the final comparison. It expects a Google Drive folder `MyDrive/sonar_project` containing `sonar.py`, `Cnn14_mAP=0.431.pth`, the 13 cache files and the two milestone models. Training is seeded, but GPU runs are not bit-for-bit repeatable, so small differences from the stored numbers are expected.

## Run settings (from the metadata in each result file)

| Run | Training clips | Epochs | Batch | Device | Time |
|---|---|---|---|---|---|
| Scratch CNN, S1 full | 36,510 | 15 | 64 | laptop CPU | 39.6 min |
| Scratch CNN, S1 full, 50 Hz floor | 36,510 | 15 | 64 | T4 GPU | 3.0 min |
| Scratch CNN, mixed | 24,000 | 15 | 64 | T4 GPU | 2.6 min |
| PANNs, S1 subset | 4,000 | 6 (3 head only + 3 fine-tuning) | 16 | laptop CPU | 35.3 min |
| PANNs, mixed | 24,000 | 6 (3 + 3) | 64 | T4 GPU | 6.4 min |

Training uses AdamW (weight decay 1e-4), a cosine schedule and class-weighted cross-entropy. The checkpoint with the best validation macro-F1 is kept and each test set is scored once.

## Data notes and limitations

- About 17% of S1 training clips are exact duplicates, and 6.7% to 9.2% of the test clips in each scenario are bit-identical to a training or validation clip. They were removed to make the clean test sets used for every result.
- VTUAD has no recording identifiers, so a recording-grouped split was not possible.
- DeepShip comes from the same Ocean Networks Canada region as VTUAD, so it tests different ships and recordings, not a different location.
- Single seed for every final run; PANNs was fine-tuned for six epochs and may be under-trained; mixed training is capped at 24,000 clips (memory); rare-class test sets are small (clean S1 has 20 passengership and 62 tanker clips); YAMNet was not tested.
